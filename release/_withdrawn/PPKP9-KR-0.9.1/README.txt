====================================================================
 파워프로군 포켓 9  한글패치  v0.9.1
 パワプロクンポケット9 (Nintendo DS / 일본판)
====================================================================

■ 이 패치에 대해

  석세스 모드 「さすらいのナイスガイ(방랑의 나이스가이)」 시나리오를
  중심으로 게임 내 대사를 한국어로 옮긴 비공식 팬 번역 패치입니다.

  배포되는 것은 패치 파일 하나뿐입니다. ROM은 포함돼 있지 않으며,
  본인이 소유한 정품 카트리지의 덤프에 직접 적용해서 쓰시면 됩니다.


■ 적용 대상 ROM

  이 패치는 아래 덤프 하나에만 맞춰져 있습니다.
  다른 덤프에 적용하면 패치가 "성공"해도 게임이 깨집니다.

    파일 크기 : 67,108,864 바이트 (64 MB)
    SHA-1     : 9d37ea0bbd71bda9db9bd641460061b0ce9e3aeb
    CRC32     : 9825C3CF

  적용 후 결과물이 아래와 같아야 정상입니다.

    SHA-1     : 1d48351530cc942642b256128b06d46fe45e5742
    CRC32     : EFC348D1


■ 적용 방법

  패치 형식은 xdelta3 입니다.
  (이 ROM은 64MB라 IPS 형식은 쓸 수 없습니다. IPS는 16MB가 한계입니다.)

  [브라우저에서 — 설치 없이 / 가장 간편]
    1. https://www.marcrobledo.com/RomPatcher.js/ 접속
    2. ROM file  : 원본 .nds 선택
       Patch file: PPKP9-KR-0.9.1.xdelta 선택
    3. Apply patch → 저장
    ※ 파일은 브라우저 안에서만 처리되며 업로드되지 않습니다.

  [윈도우 프로그램]
    xdelta UI, DeltaPatcher 등에서
      원본 ROM + 이 .xdelta 파일 → 적용

  [명령줄]
    xdelta3 -d -s "Power Pro Kun Pocket 9 (Japan).nds" PPKP9-KR-0.9.1.xdelta PPKP9_kr.nds

  적용 후 checksums.txt 의 SHA-1 과 대조해 보시길 권합니다.


■ 무엇이 번역돼 있나

  · 시나리오 대사      20,487줄
  · 커버리지          대사 89.07% / 문자 95.00% / 고유 문자열 97.76%
  · 선택지            181개 블록 중 173개(95%) 전 항목 번역

  플레이 흐름에 나오는 대사와 선택지는 대부분 한국어로 나옵니다.


■ v0.9.1 변경 사항  (v0.9를 쓰고 계시면 교체를 권합니다)

  v0.9에는 선택지 항목 811곳이 깨진 글자로 나오는 결함이 있었습니다.
  원문보다 길어 별도 영역으로 보낸 항목이 그 화면에서는 해석되지 않아,
  내부 제어 바이트가 그대로 글자로 그려지고 있었습니다
  (예: 「단축한다」가 「ヴごん」으로).

  · 해당 항목은 번역을 넣지 않고 원문 일본어로 되돌렸습니다.
    읽을 수 있는 일본어가 뒤섞인 글자보다 낫다고 판단했습니다.
  · 「아니。」처럼 압축 때문에 뒷글자가 잘리던 문제도 함께 고쳤습니다.
  · 빌드에 검사 두 개를 추가해 같은 유형의 결함을 자동으로 막습니다.


■ 아직 일본어로 나오는 부분 (알려진 제한)

  아래는 번역이 안 된 것이 아니라, 게임 쪽 구조 때문에 아직 화면에
  넣지 못한 부분입니다. 번역문 자체는 준비돼 있습니다.

  · 능력 이름 / 능력 효과 설명 / 인물사전 / 일일 행동 메뉴
      → 이 화면들은 대사 엔진과 다른 글꼴 경로를 써서, 한글을 넣으면
        글자가 깨집니다. 깨진 한글보다 원문이 낫다고 판단해 뺐습니다.
  · 오프닝 컷신
  · 「ハンサムが７上がった」 같은 능력치 증감 메시지
  · 일부 짧은 선택지 (「鎖」「妹」 등)
      → 원문이 2바이트뿐이라 한글을 넣을 공간이 물리적으로 없습니다.
  · 원문보다 길어진 선택지 706개
      → 선택지 화면은 별도 영역을 참조할 수 없어 원문을 유지합니다.
        (짧게 다시 쓸 수 있는 것은 앞으로 줄여 나갈 예정입니다)

  · 시합 / 미니게임 진입 구간은 아직 검증하지 못했습니다.
    이상이 있다면 이 부분일 가능성이 높습니다.


■ 확인된 동작 범위

  콜드 부팅 → 타이틀 → 캐릭터 생성 → 오프닝 → 게임 시작(4월 8일)
  → 상점가 이벤트 → 선택지 → 행동 선택 → 연습 → 강가 이벤트 → 다음 날

  위 구간을 에뮬레이터(DeSmuME)에서 반복 확인했습니다.
  실기 및 다른 에뮬레이터에서는 검증하지 않았습니다.


■ 주의

  · 세이브 데이터는 원본과 호환되지만, 패치 적용 전후로 세이브를
    백업해 두시길 권합니다.
  · 번역 품질에 대한 제보(오역, 어색한 문장, 깨진 글자)는
    어느 화면 어느 대사였는지 함께 알려주시면 도움이 됩니다.


■ 라이선스 / 면책

  이 패치는 비영리 팬 번역이며 코나미와 무관합니다.
  패치 파일에는 원 게임의 데이터가 포함돼 있지 않습니다.
  ROM 파일의 배포·요청·공유는 하지 말아 주세요.
