 파워프로군 포켓 9  한글패치  v0.1
 パワプロクンポケット9 (Nintendo DS / 일본판)
====================================================================

■ 이 패치에 대해

  석세스 모드 「さすらいのナイスガイ(방랑의 나이스가이)」 시나리오를
  중심으로 게임 내 대사를 한국어로 옮긴 비공식 팬 번역 패치입니다.

  v0.1은 첫 정식 번호 배포판입니다. 아직 손볼 곳이 많습니다.
  (이전에 배포됐던 0.9.x는 훨씬 이른 시점의 시험판이며 폐기됐습니다.
   번호는 작지만 v0.1이 최신입니다.)

  배포되는 것은 패치 파일 하나뿐입니다. ROM은 포함돼 있지 않으며,
  본인이 소유한 정품 카트리지의 덤프에 직접 적용해서 쓰시면 됩니다.


■ 적용 대상 ROM

  이 패치는 아래 덤프 하나에만 맞춰져 있습니다.
  다른 덤프에 적용하면 패치가 "성공"해도 게임이 깨집니다.

    파일 크기 : 67,108,864 바이트 (64 MB)
    SHA-1     : 9d37ea0bbd71bda9db9bd641460061b0ce9e3aeb
    CRC32     : 9825C3CF

  적용 후 결과물이 아래와 같아야 정상입니다.

    SHA-1     : 1923037a73d4d804ee57529bd4e6f582a4f48e65
    CRC32     : D2EE93DA


■ 적용 방법

  패치 형식은 xdelta3 입니다.
  (이 ROM은 64MB라 IPS 형식은 쓸 수 없습니다. IPS는 16MB가 한계입니다.)

  [브라우저에서 — 설치 없이 / 가장 간편]
    1. https://www.marcrobledo.com/RomPatcher.js/ 접속
    2. ROM file  : 원본 .nds 선택
       Patch file: PPKP9-KR-0.1.xdelta 선택
    3. Apply patch → 저장
    ※ 파일은 브라우저 안에서만 처리되며 업로드되지 않습니다.

  [윈도우 프로그램]
    xdelta UI, DeltaPatcher 등에서
      원본 ROM + 이 .xdelta 파일 → 적용

  [명령줄]
    xdelta3 -d -s "Power Pro Kun Pocket 9 (Japan).nds" PPKP9-KR-0.1.xdelta PPKP9_kr.nds

  적용 후 checksums.txt 의 SHA-1 과 대조해 보시길 권합니다.


■ 무엇이 번역돼 있나

  · 석세스 시나리오 대사·선택지·행동 커맨드·상태 메시지 대부분
  · 화면에 그려지는 일본어 글자 자리 중 91.4% 가 한국어로 대체됨
    (남은 자리 40,853 곳 — 대부분 아래 「알려진 제한」에 해당)
  · 한글 글꼴: 12px 굴림 계열, 확장 글리프 페이지 사용


■ 알려진 제한 (v0.1)

  [아직 일본어로 남는 것 — 번역은 있으나 구조상 못 넣은 부분]
  · 아이템 입수/소모 메시지(「手に入れた！」「無くなった！」),
    「練習がレベルアップした！」, 「仲間評価」, 「呪いの人形」 등
      → 파일8/25에 여유 영역이 없어 원문보다 긴 번역을 못 싣습니다.
  · 「連邦」「ルナリング」「デスパレス」 등 고유명사 일부
  · 배회하기 커맨드 일부, 「栄養不足」 류 짧은 상태문
  · 「でも」「ねえ」 같은 2바이트 짧은 말 — 한글을 넣을 공간이 없습니다.
  · 능력 이름·인물사전 화면은 별도 글꼴 경로라 일부만 한국어

  [그래픽]
  · 「能力」 타이틀, 게임오버 화면의 굵은 글씨, 캐릭터 생성 화면 등은
    이미지라서 이번 판에는 손대지 않았습니다(보류).
  · 이름 입력의 「漢字」 탭은 한자 후보 대신 한글 조각이 보입니다.
    한자 변환 기능은 한글 글꼴 공간 확보를 위해 포기했습니다.

  [확인 중인 결함]
  · 게임오버 화면에서 대사창이 비고 멈춘다는 보고(구 빌드)가 있습니다.
    원인으로 추정되는 코드 오염은 고쳤으나 v0.1에서 재확인은 못 했습니다.
  · 특정 장면에서 깨진 글자(「グべゅぁ」)가 보인다는 보고 — 재현 세이브 필요.
  · 선택지 항목 겹침(잔상)은 이번 판에서 수리했습니다. 수비훈련·달리기·
    회차 선택·낚시 선택지에서 잔상이 보이면 제보 바랍니다.
  · 시합(페넌트·미니게임 포함) 장시간 플레이는 검증하지 못했습니다.


■ 확인된 동작 범위 (에뮬레이터 DeSmuME)

  콜드 부팅 → 타이틀 → 신규 게임(이름 입력) → 프롤로그 완주 → 시나리오
  전환 → 상점 이벤트 → 행동 선택 → 훈련 서브메뉴 → 만세(バンザイ) 연출
  완주 → 세이브 이어하기 → 야구선인 대사.
  실기 및 다른 에뮬레이터에서는 검증하지 않았습니다.


■ 주의

  · 세이브 데이터는 원본과 호환되지만, 패치 적용 전후로 세이브를
    백업해 두시길 권합니다.
  · 원본 ROM용 Action Replay 치트는 이 패치에서 주소가 어긋납니다
    (석세스 데이터 블록이 뒤로 밀림). 치트를 쓰면 진행이 깨질 수 있습니다.
  · 번역 품질에 대한 제보(오역, 어색한 문장, 깨진 글자)는
    어느 화면 어느 대사였는지 스크린샷과 함께 알려주시면 도움이 됩니다.


■ 라이선스 / 면책

  이 패치는 비영리 팬 번역이며 코나미와 무관합니다.
  패치 파일에는 원 게임의 데이터가 포함돼 있지 않습니다.
  ROM 파일의 배포·요청·공유는 하지 말아 주세요.
