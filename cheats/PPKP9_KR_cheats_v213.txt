================================================================================
 파워프로군 포켓9 한글패치 전용 Action Replay 치트 (v211~v213 빌드용)
================================================================================
 원전: https://w.atwiki.jp/tentoumusi/pages/157.html (원본 ROM용 PAR 코드)
 변환: 세션44 — 한글패치 빌드는 오버레이를 +0x72000 키우므로 석세스 힙 블록이
       전부 0x72000 만큼 뒤로 밀린다. 아래 코드는 그 델타를 반영한 것이다.

 ⛔ 반드시 읽을 것
 - 이 파일은 「빌드 로그에 overlay grows 0x72000 이 찍힌 빌드」 전용이다
   (v211_f20 / v212_banzai / v213_ops). 원본 ROM이나 v210 이전엔 원전 코드를 쓸 것.
   REGION_CAP 을 바꿔 다시 빌드하면 델타가 달라져 이 파일도 다시 만들어야 한다.
 - ROM 에는 절대 적용하지 말 것. 에뮬레이터의 치트 기능에 등록해서 쓴다:
     DeSmuME : Emulation → Cheats → List → Add → 「Action Replay」 탭에 붙여넣기
     melonDS : System → Setup cheat codes → New AR code
 - 검증 상태 표기:
     [검증] = 세션44가 v213 실기 메모리에서 값 자체를 확인
     [추정] = 같은 델타(+0x72000)를 적용했으나 그 모드에 진입해 확인하진 못함
 - 「さすらいのナイスガイ」 계열 가드(5233CB60 0233E440)는 v213 에서 상점 이벤트와
   행동 선택 화면 두 시점에 관측한 값이다. 세이브 슬롯·진행에 따라 달라질 수 있으니
   코드가 안 먹으면 가드 두 줄을 지우고 «그 모드에서만» 켜는 방식으로 쓸 것.

변화구 변경 — 원전 표의 222C9Exx 를 2233BExx 로 읽으면 된다 (값표는 원전 그대로):
  슬라이더계 2233BE84 000000xx / 커브계 2233BE88 / 포크계 2233BE8C
  싱커계 2233BE90 / 슈트계 2233BE94 / 제2변화구 2233BEA0
  xx 값: E0 슬라이더 E4 커브 EA 포크 F3 싱커 F6 슈트 … (원전 표 참조)
변화구 변화량 7: 원전 222CAzzz → 2233Czzz 00000007 (zzz 표는 원전 그대로)

야수용 전 특수능력 / 투수용 전 특수능력 / 오리지널 볼 / 타법·서브포지션 변경 /
초특수능력 — 전부 같은 규칙: 원전의 222C9xxx→2233Bxxx, 222CAxxx→2233Cxxx,
022C9xxx→0233Bxxx 로 치환하고 가드를 5233CB60 0233E440 로 바꾸면 된다.
(줄이 많아 생략 — 필요하면 말해 달라, 전부 펼쳐서 넣어 준다.)
